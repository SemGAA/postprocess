# Постобработка OCR паспорта РФ

Проверка результатов распознавания российских
паспортов. 
Для каждого документа скрипт принимает одно из двух решений:
`accept`, если всем полям можно доверять, или `reject`, если документ лучше
переснять.

Основной приоритет решения состоит в том, чтобы не принимать документы с
ошибками. Лишний отказ допустим и стоит дешевле ошибочного принятия.

## Подход

Скрипт выполняет следующие проверки:

- наличие всех 10 полей;
- общая и посимвольная уверенность OCR;
- качество изображения;
- формат дат, пола, номера паспорта и кода подразделения;
- совпадение даты рождения, даты выдачи, пола, кода и фамилии с MRZ;
- наличие кода подразделения в справочнике;
- действительность паспорта на 01.10.2026.

Пороги подобраны на train. В итоговой конфигурации на 3000 документах принято
17 документов без ошибок.

## Структура

- `postprocess.py` содержит всю логику постобработки;
- `answers.jsonl` содержит готовые ответы для test;
- `report.md` содержит краткий отчёт и прогноз;
- `reference/subdivisions.csv` содержит справочник подразделений;
- `evaluate.py` проверяет ответы на размеченной выборке.

## Запуск

Требуется Python 3.10 или новее. Дополнительные библиотеки и доступ к интернету
не нужны.

Исходные файлы должны находиться в папке `data`. Команда для обработки test:

```bash
python postprocess.py data/test_predictions.jsonl answers.jsonl
```

Проверка на train:

```bash
python postprocess.py data/train_predictions.jsonl train_answers.jsonl
python evaluate.py train_answers.jsonl data/train_labels.jsonl
```

Ожидаемый результат:

```text
документов:              3000
принято верно:           17  (0.6%)
принято с ошибкой:       0
ошибки по полям:
```

Проверка воспроизводимости готового test-ответа:

```bash
python postprocess.py data/test_predictions.jsonl answers_check.jsonl
cmp answers.jsonl answers_check.jsonl
```

Пустой вывод `cmp` означает, что файлы совпадают. В `answers.jsonl` находится
2000 ответов: 29 документов принято, 1971 отклонён.
